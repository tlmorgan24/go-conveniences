To use in your Go project, run this: `go get github.com/tlmorgan24/go-conveniences`.

Then e.g. if want to use the `intmath` package in a file, add this import statement: `import "github.com/tlmorgan24/go-conveniences/intmath"`. If using gopls, may be able to simply start writing e.g. `intmath.Sqrt(x)` and saving will automatically add the import statement.
